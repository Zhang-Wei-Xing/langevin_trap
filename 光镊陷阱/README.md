# 三维布朗粒子光镊势阱模拟

这是一个单文件交互网页，用来观察过阻尼布朗粒子在三维谐振光镊势阱中的运动。日常使用只需要打开：

```text
网页UI.html
```

网页不需要后端服务，也不需要安装额外程序。双击文件，或用浏览器打开它即可。

## 快速上手

1. 打开 `网页UI.html`。
2. 默认参数会自动跑出一组结果；改完参数后点击左侧的“运行模拟”。
3. 左侧每个参数都有数字框和滑杆。可以拖滑杆快速探索，也可以在数字框里输入精确数值。
4. 用右侧上方的标签切换图表。
5. 用“平面 x-y”按钮在 `x-y`、`y-z`、`z-x` 之间循环切换。
6. 点击 `PNG` 下载当前画布。

## 左侧控件

控件按用途折叠成几组。常用的几组默认展开，不常改的“数值与采样”和“初始位置”默认收起。

| 分组 | 主要作用 |
| --- | --- |
| 势阱刚度 | 调 `kappa x`、`kappa y`、`kappa z`。越大，粒子在对应方向被束缚得越紧。 |
| 热环境 | 调粒子半径 `a`、黏滞系数 `eta`、温度 `T`。下面会实时显示由这些参数导出的阻尼和扩散量。 |
| 硬墙与随机约定 | 开关硬墙，设置墙面位置 `wall z min`，以及随机积分参数 `alpha`。 |
| 恒定力 | 开关恒定外力，并分别设置 `F x`、`F y`、`F z`。 |
| 数值与采样 | 调时间步长、总时间、密度分箱数，以及 C/D 曲线每个 bin 的采样数。 |
| 初始位置 | 设置粒子开始时的 x、y、z 坐标。 |

带“开启/关闭”的按钮是开关。硬墙关掉后，z 方向不再有墙面限制；恒定力关掉后，三个方向的外力都按 0 处理。

部分滑杆是对数滑杆，比如刚度、温度、时间步长和采样数。它们适合跨数量级调节；如果需要精确值，直接改右侧数字框。

## 图表标签

右侧标签都来自同一次模拟结果。切换标签不会重新模拟，只有点击“运行模拟”才会用当前参数重新生成轨迹。

| 标签 | 看什么 |
| --- | --- |
| 3D轨迹 | 三维运动轨迹。蓝点是起点，红点是终点，颜色沿时间变化；硬墙开启时会画出墙面。 |
| 位置分布 | 当前轴组中两个坐标的一维直方图，并叠加理论分布线。 |
| 实测密度 | 从模拟轨迹统计出的二维密度热图。 |
| 理论密度 | 按当前参数直接计算出的理论二维密度热图。 |
| 漂移 C | 当前轴组中两个坐标的漂移曲线；实线来自单步采样，虚线是理论线。 |
| 扩散 D | 当前轴组中两个坐标的扩散曲线；实线来自单步采样，虚线是理论线。 |
| ACF | x、y、z 三个方向的位置自相关函数，以及对应参考理论线。 |
| MSD | x、y、z 三个方向的平均平方位移，以及对应参考理论线。 |

“平面/轴”按钮的文字会跟着当前标签变化。对 3D 轨迹、实测密度、理论密度，它表示当前二维平面；对位置分布、漂移 C、扩散 D，它表示当前显示的两个坐标轴。

## 结果摘要

左下角的状态区会显示当前是否运行完成，以及某些图表的额外计算耗时。状态区下面的摘要会列出总时间、步数、最终位置、均值、标准差、由方差反推的刚度等量。

如果切到 C/D、ACF 或 MSD 时稍等一下，是因为这些曲线会在第一次打开对应标签时再计算。后续再切回来会直接使用已经算好的结果。

## 调参提示

- `dt` 越小，轨迹更细，但运行更慢。
- `total time T` 越大，统计越稳定，但步数也越多。
- `density bins` 越大，密度图越细；太大时单个格子的噪声也会更明显。
- `ensemble / bin` 越大，漂移 C 和扩散 D 曲线越平滑；太大时切换到 C/D 标签会更慢。
- `seed = -1` 表示每次使用新的随机序列；设成固定整数可以复现实验。
- 硬墙靠近粒子活动区域时，z 方向分布、漂移和扩散会明显改变。
